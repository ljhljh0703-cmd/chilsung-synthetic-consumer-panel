## 정규화

`python3 population/stats/normalize.py`를 프로젝트 루트에서 실행한다.

`population_cells.csv`: `province,sex,age_band,population` 306행 = 17시도 × 2성 × 9연령구간. 단위 명.

- 19세는 age_band 10으로 따로 보존한다. 20..90은 각각 20~29..90~99세이다.
- 19~99세 분모: **43,969,023명**.
- 제외한 0~18세: 7,139,629명, 100세 이상: 8,726명.
- 전국 합계 행을 시도 합계에 중복해서 넣지 않는다.
- 100세 이상은 NVIDIA 원본에 관측되지 않아 별도 제외하고, 90대에 합치거나 가짜 인물을 만들지 않는다.
- 강원특별자치도·전북특별자치도는 원표 이름 그대로 보존. 원본 페르소나의 강원·전북 등 별칭 정규화는 빌더 책임.

## 검사

실행한 검사 모두 통과:

1. 원자료 모든 행에서 남자 + 여자 = 총인구.
2. 모든 연령(계·0~99·100세 이상)에 대해 17시도 합계 = 전국 값.
3. 시도·연령 키 중복 0, 원자료 18 × 102 = 1,836행(헤더 제외).
4. 정규화 306칸 전부 양수, 19~99세 합계 + 제외 연령 합계 = 전체 인구 51,117,378명.
