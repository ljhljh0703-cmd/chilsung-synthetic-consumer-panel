# 보정 탐색 계획 (사전 등록 FIT 이후 추가, 판정에 쓰지 않는 탐색)

사전 등록 FIT 판정(대표성 미달)은 바꾸지 않는다. 이 문서는 그 뒤에 「무엇을 바꾸면 기관 통계에 가까워지는가」를 작은 표본에서 먼저 보고, 효과가 보이는 것만 표본을 늘리는 탐색 계획이다. 모든 결과는 「탐색」으로 표시하고, 효과가 없어도 그대로 공개한다.

## 관찰된 문제 (FIT 조합 3)
- 분포 압축: 폭음률 실제 7~55% → 0~8%, 막걸리 52.3% → 5.2%, 리큐르 13.2% → 0%
- 남녀 차이 과장: 월간음주율 차이 실제 16.8%p → 50.8%p
- 순위는 대체로 맞음(주종 순위 상관 0.96)

## 시험군 (문항 A, 한 명씩 질문, 인물 소개는 FIT 조합 3과 같음, 이름은 「이 사람」으로 바꿈)
| 군 | 모델 | 바꾸는 것 | 겨냥하는 문제 |
|---|---|---|---|
| A 분포 응답 | terra | 보기 하나를 고르는 대신 이 사람이 각 보기를 고를 확률을 답하게 하고, 고정 난수로 그 확률에서 답 하나를 뽑음(V3는 주종마다 0~1 확률, 주종별로 따로 뽑음) | 분포 압축 |
| B 기준값 제공 | terra | 시스템 안내에 「한국 성인 월간음주율은 남자 68.2%, 여자 51.4%(국민건강영양조사 2024)」 한 줄 추가 | 남녀 차이 과장, 전반 수준 |
| C 분포 + 기준값 | terra | A와 B를 함께 | 둘 다 |
| D 분포 응답 | haiku | A와 같음 | 모델 차이 |

- B·C는 V1 통계를 알려 주므로 V1은 평가에서 뺀다(보정에 쓴 자료). V2·V3만 본다.
- 기준값 외 다른 기관 수치(폭음률, 주종 비율)는 어떤 군에도 넣지 않는다.

## 1단계 선별 (FIT 300명의 1/10)
- 표본: FIT 300명에서 성·연령 6칸마다 5명씩, 고정 난수 20261104로 뽑은 30명. 군마다 같은 30명, 1회.
- 비교 기준: 같은 30명의 FIT 기존 응답(terra = 조합 3 반복 1, haiku = 조합 4 반복 1). 새 호출 없음.
- 주 지표: 뽑은 답 기준. 보조 지표: 확률 합으로 낸 기대값(A·C·D만).
- 보는 값: V2 전체 월간폭음률(성·연령 가중)과 기관 37.8%의 차이, V3 10종 평균 절대 차이와 순위 상관, V3 상위 2개, V1 남·여 차이(A·D만).
- 2단계로 올리는 조건(실행 전 고정): 같은 30명 기준 대비 ① V2 전체 폭음률 차이가 10%p 이상 줄고 ② V3 평균 절대 차이가 3%p 이상 줄며 ③ V3 상위 2개가 맥주·소주로 유지. 조건을 넘은 군 중 ①+② 감소 합이 큰 순서로 최대 2개.

## 2단계 확대 (FIT 300명 전체, 1회)
- 올라간 군만 FIT와 같은 300명에 1회.
- FIT 사전 등록 7절 RQ1 기준을 그대로 적용해 자료별 「기준 충족 / 미충족」을 적는다(B·C는 V2·V3만). 반복 3회가 아니므로 판정이 아닌 탐색 결과로만 쓴다.
- 3단계(3회 반복으로 FIT와 같은 조건)는 2단계 결과를 보고 작가가 정한다.

## 상한과 중단
- 전체 요청 900건 이하(재요청 포함). 1단계 120건 + 재요청, 2단계 최대 600건 + 재요청.
- 형식 제외율이 군에서 5%를 넘으면 그 군은 「판정 불가」.
- 크레딧 소진 시 FIT와 같은 규칙(같은 모델 로그인 경로, 한 군 안에서 섞지 않음).

## 해석 한계
- 30명 선별은 큰 효과만 걸러 낸다. 칸별 비교는 하지 않는다.
- 기준값 제공은 실제 운영에서 「공개 통계로 보정」에 해당하며, 보정에 쓴 자료로는 검증하지 않는다.
- 효과가 있어도 기관 통계 재현일 뿐 신제품 예측력은 아니다.

## 2차 선별 추가 (2026-11-04 20시 30분, 1차 결과를 본 뒤 작가 결정 「2차 작게 한 번 더」. 실행 전 공개 커밋)
1차 결과: A(분포 응답) V2 오차 10.85%p 감소, V3 2.02%p 감소로 미충족. C는 V3 3.91%p, V2 0.60%p로 미충족. B 미충족. D(haiku 분포 응답)는 형식 제외 3/30(10%)으로 판정 불가.

- 시험군: A2 = A와 같은 방식(terra 분포 응답)을 1차와 겹치지 않는 새 30명에. D2 = D와 같은 방식(haiku 분포 응답)을 1차와 같은 30명에, 응답 형식만 보강.
- 새 30명: FIT 300명 중 1차 30명을 뺀 270명에서 성·연령 6칸마다 5명, 고정 난수 「20261104-2」.
- 형식 보강(두 군 모두 같은 규칙): 예시 JSON을 문항 끝에 붙이고, 보기 확률 합이 0.95~1.05면 합 1로 나눠 맞춤, 그 밖이면 재요청 1회 뒤 제외. V3 주종별 확률은 0~1 범위 밖이면 재요청.
- 비교 기준: 같은 사람들의 FIT 기존 응답(terra = 조합 3 반복 1, haiku = 조합 4 반복 1). 새 호출 없음.
- 확대 조건(1차와 같은 숫자): V2 오차 10%p 이상 감소, V3 오차 3%p 이상 감소, V3 상위 2개 맥주·소주.
  - A 계열은 1차 30명과 2차 30명을 합친 60명으로 판정한다(주 판정). 2차 30명 단독 값도 함께 적는다.
  - D2는 2차 30명으로 판정한다. 형식 제외가 5%를 넘으면 판정 불가.
- 확대: 조건을 넘은 군만 FIT 300명 1회(1차 계획 2단계와 같음).
- 상한: 1차 사용분 포함 전체 900건 이하.
